# Phase 4: RV64C expansion foundation

Implementation and verification: 2026-10-01 America/New_York (2026-10-02
UTC). Phase 4 is in progress; the processor does not yet execute RVC.

Added `rtl/rv64xo3_rvc.sv`, a combinational RV64C integer expander covering
arithmetic, word operations, loads/stores, stack addressing, branches,
J/JR/JALR and EBREAK. Reserved and unsupported floating-point encodings
assert illegal and return zero. Integer hints retain harmless semantics.
The input is a compressed halfword; ordinary 32-bit instructions must
bypass this module in the future fetch integration.

Encoding reference: [RISC-V C extension v2.0](https://docs.riscv.org/reference/isa/unpriv/c-st-ext.html).
The independent oracle contains 305 compressed/base instruction pairs
assembled and linked with GNU binutils from xPack GCC 13.2.0-2. It covers
register extremes, signed immediate boundaries, shifts through 63,
RV64-specific LD/SD/ADDIW/ADDW/SUBW, and forward/backward control transfers.
Regenerate `tb/cocotb/rvc/vectors.json` with its neighboring
`generate_vectors.py` and `riscv-none-elf-*` in PATH (or set RISCV_PREFIX).
Checked-in vectors let CI run without a cross toolchain. Additional tests
reject reserved, FP and non-compressed inputs. The runner is part of
`make cocotb` and the CI smoke selection; standalone lint checks the
expander even though it is not yet instantiated by the processor.

`make regress` passed unit 58/58, cocotb runners 9/9 (including both new RVC
tests), C++ 15/15, RV64UI 54/54, RV64UM 13/13, RV64MI 15/15,
RV32UI 37/37 and RV32UM 8/8. Verilator lint passed; Verible unavailable.
Log: build/phase4-regress.log.

Remaining Phase 4 integration:

1. Assemble two mixed-length instructions at every halfword offset, including
   32-bit instructions crossing 64-bit parcels; retain buffers across stalls
   and discard partial instructions on redirect.
2. Carry original instruction, per-slot PC and length through decode/execute;
   use length for sequential PC, prediction, recovery and JALR link values.
   In particular, expanding C.JALR must still write pc+2, not pc+4.
3. Update target alignment and CSR reporting consistently before advertising
   C in misa. Preserve original compressed bits for illegal-instruction mtval.
4. Add mixed-length, c.j/c.jr/c.jalr, straddler and alignment-trap processor
   tests and compressed compliance, then rerun every phase gate. Phase 5
   atomic operations and Phase 6 OoO remain subsequent work.
